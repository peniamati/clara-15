Conectar la playlist de Clara

Usá la cuenta de Spotify dueña o colaboradora de la playlist. Se solicita permiso de lectura; esta página no agrega ni elimina canciones.

Copiá este valor en GitHub como un nuevo Repository secret llamado SPOTIFY_REFRESH_TOKEN. No lo compartas en mensajes ni lo guardes en el código.

Después ejecutá de nuevo Deploy to GitHub Pages con Run workflow.
